# Pacote para upload pelo navegador

Foram omitidas quatro cópias idênticas de tokenizer.json (11,4 MB cada), uma por adaptador. O tokenizador é carregado do modelo base Qwen/Qwen3-0.6B nos scripts fornecidos, e não dessas cópias. Os pesos adapter_model.safetensors, configurações, templates, logs e datasets foram mantidos.

Os arquivos tokenizer.json podem ser obtidos novamente do modelo base. O manifesto de integridade deste pacote exclui somente os quatro arquivos omitidos. Os resultados de análise e inferência originais não foram alterados. Nenhum novo treinamento foi realizado.

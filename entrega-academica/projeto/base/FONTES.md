A base consultável contém 7 trechos em JSON UTF-8. O arquivo conhecimento.json foi preservado para manter a correspondência com os resultados congelados. A verificação dos endereços em 14/11/2026 é posterior aos experimentos e não altera suas entradas.

O conteúdo do JSON é resumido, não uma cópia integral dos documentos. A licença do portal não foi automaticamente atribuída aos resumos. As condições de publicação de adaptações e redistribuição devem ser conferidas pela autora antes de ampliar o uso. O acesso público a um endereço não equivale a uma licença irrestrita.

Os IDs, URLs e detalhes estão em fontes.json. Os cenários sintéticos em dados/ e os 32 exemplos de treino JSON são dados autorais do experimento, separados da base recuperada. Os 100 casos fictícios do site não integram esta base textual nem foram usados para treinar o adaptador de linguagem.
